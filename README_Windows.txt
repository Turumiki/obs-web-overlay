==========================================================
  カウントダウン オーバーレイ (Windows 版)
==========================================================

OBS にカウントダウンタイマーを表示し、別ウィンドウの操作盤から
時間設定・開始/停止・±調整・デザイン編集をリアルタイムで行えます。

----------------------------------------------------------
■ 必要なもの
----------------------------------------------------------
・Node.js (LTS版)  ※未インストールなら https://nodejs.org/ja から入れてください
・OBS Studio

----------------------------------------------------------
■ 起動方法
----------------------------------------------------------
1. このフォルダの「Start_Windows.bat」をダブルクリック
2. 黒いウィンドウが開き、URL が表示されれば起動成功
   (このウィンドウは閉じないでください＝閉じるとサーバーが止まります)

----------------------------------------------------------
■ 操作盤を開く
----------------------------------------------------------
ブラウザ (Chrome/Edge 等) で次を開く:

    http://localhost:8090/

ここで時間セット・開始/停止・±5分・デザイン編集ができます。

----------------------------------------------------------
■ OBS に表示する (ブラウザソース)
----------------------------------------------------------
1. OBS の「ソース」→「+」→「ブラウザ」を追加
2. URL に次を入力:

    http://localhost:8090/overlay

3. 幅・高さは キャンバスと同じ (通常 1920 x 1080) に設定
4. 位置は 0, 0 (左上)。拡大縮小はしない
5. 「表示されていないときにシャットダウン」は OFF 推奨

  ※ 別PCのOBSから使う場合は localhost ではなく、
     起動時に表示される「http://192.168.x.x:8090/overlay」を使う
     (同じLAN内で、ファイアウォールが 8090 番を許可していること)

----------------------------------------------------------
■ 困ったとき
----------------------------------------------------------
・「Node.js が見つかりません」と出る
    → Node.js (LTS) をインストールしてから再度 bat を実行
・ポートが使用中エラー
    → 既に起動済みのウィンドウがないか確認。あれば閉じてから再起動
・OBS にタイマーが出ない
    → ブラウザソースの URL と、サーバーのウィンドウが開いたままか確認
    → ブラウザソースを右クリック →「更新」
